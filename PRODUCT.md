# Product

## Register

product

## Users

Ladder Global agency team (4-5 members: designers, developers, management). Internal-only. They open this tool mid-task to check project stage status, assign work, update progress, and confirm sync with Google Sheets. No clients access it. Usage is frequent but brief — they want to get in, see what's happening, and get out.

## Product Purpose

A single-screen internal dashboard for tracking client website projects through four workflow stages: Questionnaire, Kickoff Meeting, UI/UX Design, and Development. Syncs live to Google Sheets for reporting. Success means the team always has an accurate, readable view of every active project without needing to check Slack or email.

## Brand Personality

Professional, sharp, owned. The tool should feel like something the agency built with intention — not a bootstrapped template. Three words: precise, grounded, capable.

## Anti-references

- Overly minimal designs with no visual hierarchy or weight — things that feel like someone stripped out all the craft
- Bootstrap admin templates (navy sidebar, generic table rows, no visual personality)
- Colorful kanban/CRM tools (HubSpot, Trello) — too playful, too much color noise for a focused workflow tool

## Design Principles

1. **Every element should feel intentional** — no decorative chrome, no filler padding, no visual noise that doesn't earn its presence
2. **Hierarchy through weight, not color** — the brand red is an accent, not a crutch; size and weight carry hierarchy
3. **Data clarity first** — project status and progress must be readable at a glance; the interface serves the data, not the reverse
4. **Grounded darkness** — the dark theme should feel like a deliberate professional choice, not a cosmetic overlay over a light UI

## Accessibility & Inclusion

- WCAG AA minimum contrast for all text
- Status colors must not rely on hue alone (include labels)
- Keyboard navigable modals and forms
